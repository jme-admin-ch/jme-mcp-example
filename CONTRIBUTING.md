# Contributing to jme-mcp-example

jme-mcp-example source code is open source software released under the [Apache License 2.0](./LICENSE).

## External contributions cannot be accepted currently

At this point in time, jEAP and its JME (jEAP Microservice Examples) are released as open source software based
on the [EMBAG](https://www.fedlex.admin.ch/eli/cc/2023/682/de) law.

We do not currently accept external contributions. Please refrain from providing code changes or pull requests as we are
unable to accept them.

## Reporting Security Vulnerabilities

If you would like to report a potential security issue in this repository, please follow the procedure described in
[SECURITY.md](./SECURITY.md).
